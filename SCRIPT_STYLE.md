# Script Style Guide — "American Narration, African Soul"

House formula for every video on this channel:

## Visual style (keep identical every time)
- **Setting**: African village / river / savanna, warm golden light, baobab trees
- **Look**: Pixar-quality 3D animated short (Blender render feel), 9:16 vertical
- **Character**: consistent hero (e.g. elderly fisherman: straw hat, mustard shirt)
- **Grade**: warm amber/golden-hour palette, volumetric mist, cinematic DOF

## Script style (American YouTube storyteller)
Write narration the way top American narration channels do — NOT a formal folktale:

1. **Cold-open hook in first 5 seconds** — a question or impossible situation:
   "What would you do if you found a bag full of gold... and no one was watching?"
2. **Direct address** — talk TO the viewer ("you"), never lecture.
3. **Short punchy sentences.** Fragment sentences are fine. For drama.
4. **Present tense for action**, past only for backstory.
5. **Escalation beats**: setup → temptation → choice → climax → payoff.
6. **One-line moral, spoken plainly** at the end (no text card):
   "Honesty planted today becomes tomorrow's harvest."
7. **Contrast + specifics**: numbers ("ten boats"), names ("Mama Zainab"),
   sensory verbs ("the drums began to beat").
8. **Pauses**: use "..." where the narrator should breathe.

- NO intro title text — the visual hook carries the opening
- NO moral end card — the moral is SPOKEN over the final scene, slow fade out
